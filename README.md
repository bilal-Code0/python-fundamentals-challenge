# 🐍 Python Fundamentals Challenge

**3 Projects · 3 Difficulty Levels · No External Dependencies**

A collection of three progressively challenging Python projects designed to build programming fundamentals through practical problem-solving.

Whether you're learning Python for the first time or want to test your understanding, these challenges focus on writing real programs independently rather than following step-by-step tutorials.

## 🎯 The Challenges

| Level | Project | Difficulty | Main Concepts |
|---|---|---|---|
| 01 | [Text Inspector](challenges/01-text-inspector.md) | Beginner | Strings, loops, indexing, functions |
| 02 | [Mini Store Checkout](challenges/02-mini-store-checkout.md) | Intermediate | Calculations, validation, exception handling |
| 03 | [Secret Message Encoder](challenges/03-secret-message-encoder.md) | Hard | Algorithms, modular arithmetic, encryption |

### Level 01 — Text Inspector

Build a CLI application that analyzes text, counts characters, finds positions, and performs basic string transformations.

### Level 02 — Mini Store Checkout

Develop a checkout system that processes two products, calculates totals, applies discount coupons, handles payments, and validates user input.

### Level 03 — Secret Message Encoder

Implement a Caesar cipher from scratch, supporting encryption, decryption, uppercase/lowercase preservation, negative shifts, and wraparound.

## 🚀 Getting Started

**Requirements:**
- Python 3
- A code editor
- Basic familiarity with running Python scripts in a terminal

**Instructions:**

1. Open a challenge from the table above.
2. Read its objectives, rules, and restrictions.
3. Write your solution independently in a `.py` file.
4. Run the public test cases.
5. Review and improve your implementation before moving to the next level.

No external Python packages are required.

## 📏 General Rules

- Implement all required functions.
- Follow the restrictions listed for each challenge.
- Do not hardcode outputs for specific tests.
- Use reusable functions instead of duplicating logic.
- Handle invalid inputs gracefully.
- Use Python's standard library only where permitted.
- Write readable, understandable code.

**The goal is to understand and implement the algorithms, not simply produce the expected output.**

## 🧪 Testing

Each challenge includes public function tests, CLI examples, expected results, and edge cases.

Your implementation should pass all public tests. Additional valid edge cases may also be used to evaluate correctness.

Automated test suites are planned for a future update.

## 🏆 Challenge Scoring

| Project | Maximum Points |
|---|---:|
| Text Inspector | 25 |
| Mini Store Checkout | 35 |
| Secret Message Encoder | 40 |
| **Total** | **100** |

Evaluation is based on correctness, input validation, compliance with restrictions, and code readability.

## 🌟 Optional Bonus Challenges

After completing all three levels, try extending your implementations:

- **Text Inspector:** Add case-insensitive counting through the CLI.
- **Mini Store Checkout:** Support an arbitrary number of products.
- **Secret Message Encoder:** Implement Caesar cipher shift cracking by trying all 26 possibilities.
